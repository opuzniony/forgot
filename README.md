# A tool that you can save your often used commands so they don't get lost after running other ones

Wrote most of it in a 3-hour motivation spike!

## Command List:
   - **v** - Print version
   - **save [name] [rest of string gets saved as command]** - Saves a command inside data.json in .local/bin
   - **list** - Lists all of the saved commands (does not say their contents)
   - **rm [name]** - Removes a command
   - **run [name]** - Runs a command using os.system()
